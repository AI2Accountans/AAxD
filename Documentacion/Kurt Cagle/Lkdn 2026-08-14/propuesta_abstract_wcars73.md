## 2. Propuesta de Abstract Listo para Envío (Versión en Inglés Oficial)

### Title
**Accounting & Audit by Design (A&AD): A Semantic Knowledge Graph Architecture for Continuous Auditing, XBRL GL Interoperability, and Autonomous AI Agent Verification**

### Authors
Richard Wall / A&AD Research Team (y co-autores / filiación DFRNT / AI2Accountants)

### Abstract Body (~350 words)

**Background & Problem:**  
Traditional Continuous Auditing Systems (CAS) often rely on relational databases or flat data warehouses that store static snapshots of transaction records. This architecture creates semantic silos, lacks native bitemporal traceability, and forces financial systems to rely on destructive SQL updates or ad-hoc event logs. Consequently, auditors and AI agents face significant friction when verifying multi-taxonomic financial compliance (e.g., IFRS vs. Local Tax Rules) across distributed enterprise ecosystems.

**Proposed Solution (A&AD Framework):**  
This paper introduces *Accounting & Audit by Design (A&AD)*, a novel semantic framework that unifies Continuous Auditing, Graph Databases, and International Accounting Ontologies. A&AD restructures financial entities into autonomous **Holon Graphs** governed by a triadic architecture:
1. **Knowledge & Identity Graph:** Encapsulates static metadata, contracts, and ontology constraints (UFO / SHACL 1.2).
2. **Semantic Ricordance Plane (Event Graph):** Implements an append-only, bitemporal transaction log standardizing event payloads through **XBRL GL (Global Ledger)** and **ISO 15944-4 (REA Ontology)**.
3. **State Projection Plane (Scene Graph):** Projects real-time, going-concern financial balances powered by **ACTUS actuarial state engines** and version-controlled graph commits (TerminusDB / DFRNT *Git-for-Data* paradigm).

**Key Contributions & Findings:**  
- **Multi-Taxonomic Projections:** Demonstrates how a single XBRL GL-anchored event graph dynamically projects into independent IFRS, US GAAP, and Tax Named Graphs without data duplication (via XBRL GL SRCD mapping).
- **Autonomous AI Agent Auditing:** Enables AI agents to perform zero-shot, deterministic audit checks using SHACL 1.2 validation rules and PROV-O provenance, eliminating manual reconciliation overhead.
- **Enterprise Graph Scalability:** Validates that isolating append-only event logs from state projections preserves high-throughput query performance while maintaining immutable audit trails.

**Significance:**  
A&AD bridges the gap between Semantic Web technologies (RDF/OWL/SHACL) and corporate accounting standards (XBRL GL, REA, IFRS). It establishes a blueprint for next-generation Continuous Auditing Systems where compliance is not an afterthought, but an intrinsic, immutable property of the data architecture itself.

**Keywords:** Continuous Auditing, Semantic Knowledge Graphs, XBRL GL, REA Ontology, AI Agent Verification, TerminusDB, DFRNT, Holon Architecture.
