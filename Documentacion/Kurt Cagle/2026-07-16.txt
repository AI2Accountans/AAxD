Let's start with the plumbing. The Model Context Protocol just released its biggest revision since launch. The 2026-07-28 candidate drops MCP's session handshake entirely — a tool call now carries everything it needs, so any server instance can handle it. No sticky sessions, no shared session store. New routing headers let infrastructure direct traffic without inspecting the body, and caching metadata tells clients exactly how fresh a response is. Distributed tracing is now built in too, so a single call can be followed end to end across the whole chain. The final spec ships July 28th. Okta's first out of the gate, with Anthropic and Microsoft as early adopters. Worth noting what it doesn't do, though — it's authorization to connect, not authorization for what an agent does once it's in. That's still a separate problem enterprises have to solve.

Their prediction: by 2028, over half of AI agent systems will run on context graphs, up from under ten percent today. And here's the distinction that actually matters — a knowledge graph tells you what's true right now. A context graph tells you how you got there, and why. Decision traces. Exceptions granted. The institutional memory that used to live only in the heads of people who'd been around long enough to know why the rulebook has exceptions. Gartner's sharper claim: sixty percent of agentic analytics projects relying on MCP alone will fail by 2028 without a semantic layer underneath. Not an argument against MCP — an argument that connectivity without shared meaning doesn't get you very far.

That's remarkably close to territory we've been mapping under the Holon Graph Architecture. On the standards front — the W3C's Data Shapes Working Group published a first draft of SHACL User Interfaces, formalizing something a lot of us have been assembling by hand for years: generating a data-entry form directly from a validated shape, no separate schema-to-form layer required. If you've built XForms before, this will feel very familiar.
