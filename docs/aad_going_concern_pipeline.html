A&AD: Going Concern Onboarding Pipeline

Version 1.3 — Shift Left (ISO 15944 + XForms + Base de Datos NoSQL + Plano Ricordanze)

Metodología visual para inicializar un Gemelo Digital Semántico en una entidad en marcha, anclando la confianza desde el Momento 0 hasta el Grafo Operativo con captura Shift Left (ISO 15944) en la capa contractual.

📋 Evolución del Modelo v1.3:

  • CH (Charlie): Aclaración sobre la dualidad de ACTUS (metadatos de contratos financieros vs. operacionales) y el rol de REA (flujo de eventos de negocio).
  • Shift Left Contractual (ISO 15944 & XForms): Captura en origen mediante XForms enviada a la Base de Datos NoSQL (Instancia XML) que alimenta la caja de Contratos Activos (ACTUS Framework).
  • Base de Datos NoSQL & Plano Ricordanze: La instancia XML en la Base de Datos NoSQL proyecta vistas HTML5 / PDF hacia el Semantic Ricordanze Plane (conservación del sistema legado).
1

Momento 0

Balance de Apertura estructurado en XBRL GL como el holón inmutable fundacional.

2

Contratos Activos & Shift Left

Uso de ACTUS & ISO 15944 con captura XForms, almacenamiento en Base de Datos NoSQL y proyección al Plano Ricordanze (HTML/PDF).

3

Anclaje de Confianza

El Dictamen del Auditor sella criptográficamente el balance de apertura, evitando revisiones pasadas.

4

Hidratación Histórica

Ingesta del ERP legado a un framework REA (Eventos de Negocio), expandiendo para validación SHACL.

5

Estado Destino

TerminusDB/DFRNT instanciado, listo para QOWL Queries multidimensionales y AI Zero-shot audits.
