🛡️ Technical Implementation of the 7 Habits of Provenance by Design

# Provenance Habit W3C / OMG Standard Concrete Implementation in DFRNT Stack
1 Record at the Moment of the Act W3C PROV-O (prov:Activity) Instantaneous evidence capture in BaseX with pre-transformation SHA-256 calculation.
2 Bitemporality (Two Clocks) + Actor W3C OWL-Time / Bitemporal Segregation between Valid Time (legal business date) and Transaction Time (immutable TerminusDB commit).
3 Link by Reference with IRIs W3C RDF 1.2 (Reifiers ~IRI) Formal reification without blind text fields; each EntryDetail carries a unique canonical `@id`.
4 Message Carries Its Own Lineage W3C JSON-LD / PROV-O Payload travels with prov:wasDerivedFrom pointing directly to the transaction origin and cryptographic hash.
5 Sources as Entities & Trust Score LPS Fluents / Bayesian Score Registration of external sources with continuous reliability monitoring in Prolog; alert triggers if score decays.
6 Never Overwrite; Supersede TerminusDB Git Architecture Append-only immutable graph: adjustments use prov:wasRevisionOf, preserving complete lineage and audit trail.
7 Boundary Rejection (Fail Loudly) W3C SHACL 1.2 / Poka-Yoke SHACL and Prolog customs gate deterministically blocks any orphan or unbalanced event data.
